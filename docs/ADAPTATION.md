# Адаптація під іншу компанію

## Без програміста (кабінет `/admin`)

| Розділ | Що змінюється |
|---|---|
| Тарифи | ціни за м², за стулку й балкон, доплата за санвузол, 7 додаткових послуг, мінімум, % за забруднення, % знижки для кожної регулярності, доплата за виїзд, крок заокруглення |
| Компанія | назва, опис, юр. назва, телефон, Telegram, Viber, email, години роботи, місто, територія, акцент (4 готові), строк зберігання даних |
| Гра | вимкнено / без знижки / бонус; сума, строк, мінімум наступного замовлення; список кодів і ручне погашення |
| Персонажі | характер (привітний / спокійний / грайливий), обличчя й репліки увімк./вимк. |
| Доступ | зміна пароля (закриває інші сеанси), вихід |

## Потребує правки коду (оцінюється окремо)

| Що | Де | Орієнтовно |
|---|---|---|
| Логотип і знак | `app/components/layout/LogoMark.vue`, `public/icons/icon.svg`, потім `pnpm icons` | 1–2 год |
| Повна палітра, шрифти | `app/assets/styles/_themes.scss`, `_tokens.scss`, шрифти в `nuxt.config.ts` | 2–4 год |
| Тексти сторінок, FAQ, кроки | `app/pages/index.vue`, `shared/content/services.ts` | 1–3 год |
| Що входить / не входить у послугу | `shared/content/services.ts` | 0,5 год |
| Імена й репліки персонажів | `shared/content/characters.ts` | 1 год |
| Форма чи кольори персонажів, нові моделі | `app/three/characters.ts`, `app/three/parts.ts`; GLB для Blender — `pnpm export:models` | від 4 год на героя |
| PWA-назва й кольори | `public/manifest.webmanifest`, `nuxt.config.ts` (theme-color) | 0,5 год |
| Мова, валюта, формат телефону | тексти в шаблонах, `formatUah`, `PHONE_RE` у `shared/limits.ts` | 4–8 год |

## Не входить у шаблон (окремий проєкт)

- Нові типи послуг, інша логіка ціни (за годину, за предмет).
- Онлайн-оплата й передоплата.
- Розклад і бригади, календар зайнятості, кілька ролей і менеджерів.
- CRM-інтеграції, SMS, Telegram-бот, email-сповіщення власнику про нову заявку.
- Регулярні підписки з автоматичним створенням заявок. Зараз «регулярність» — це знижка й побажання; кожен виїзд погоджується вручну.
- Автоматичне погашення бонус-кодів і захист гри від накруток.
- Кілька компаній в одному екземплярі.

## Регулярні витрати покупця

| Стаття | Орієнтовно |
|---|---|
| Хостинг Node (VPS або PaaS) | 5–20 $/міс |
| PostgreSQL (керований) | 0–25 $/міс; для старту часто вистачає безкоштовного тарифу Neon або Supabase |
| Домен | 10–20 $/рік |
| Бекапи бази | зазвичай входять у тариф PostgreSQL |

Платних API, LLM і підписок застосунок не потребує: репліки персонажів написані заздалегідь, 3D будується в браузері.
