# Формула розрахунку

Код: [`shared/pricing.ts`](../shared/pricing.ts). Один модуль використовують і браузер (живий розрахунок), і сервер. Сервер **заново рахує** кожну заявку за поточним прайсом і ігнорує суму, надіслану з браузера.

## Одна позиція

| Крок | Що відбувається |
|---|---|
| 1. База | `ціна за м² типу × площа` (Підтримуюче, Генеральне, Після ремонту). Для «Миття вікон»: `ціна за стулку × стулки` + фіксована сума за балкон/лоджію |
| 2. Санвузли | `доплата × (санвузлів − 1)` (лише для типів із площею; 0 — вимкнено) |
| 3. Додаткові послуги | `Σ ціна за одиницю × кількість` |
| 4. Сильне забруднення | `(1 + 2 + 3) × %` |
| 5. Регулярність | `(1 + 2 + 3 + 4) × −%` (щотижня / раз на два тижні / раз на місяць, окремий % для кожного) |
| 6. Заокруглення | до `roundTo` ₴ (за замовчуванням 10), половина вгору |
| 7. Кількість | `заокруглена ціна × кількість` |

«Інше» не має ціни (`null`): показується як «за фото» й ніколи як 0 ₴.

Кількість кімнат зберігається для бригади й **не впливає** на ціну. 3D-сцена ілюструє тип прибирання і не перебудовується під площу чи кімнати; у калькуляторі про це сказано прямо.

## Замовлення

```
відома сума   = Σ позицій із ціною
доплата до мін. = якщо 0 < відома сума < мінімум → мінімум − відома сума
прибирання    = відома сума + доплата
виїзд за місто = фіксована сума (якщо позначено), поверх мінімуму
разом         = прибирання + виїзд
```

Якщо в кошику лише «Інше», мінімум не застосовується, а відома сума — тільки виїзд (якщо є).

## Приклади (демо-прайс)

| Замовлення | Розрахунок | Разом |
|---|---|---|
| Підтримуюче 47 м² | 47 × 32 = 1 504 → 1 500 | 1 500 ₴ |
| Підтримуюче 20 м², за місто | 640 < 1 200 → +560; виїзд +300 | 1 500 ₴ |
| Генеральне 60 м², 2 санвузли, духовка + холодильник, сильне, щотижня | 3 720 + 200 + 650 = 4 570; +25% = 5 712,5; −15% = 4 855,63 → 4 860 | 4 860 ₴ |
| Генеральне 60 м² + вікна 6 стулок + «Інше» | 3 720 + 720 = 4 440, «Інше» — за фото | 4 440 ₴ + оцінка |

Ці приклади закріплено тестами в [`tests/pricing.test.ts`](../tests/pricing.test.ts).

## Знімок умов

У заявці зберігаються нормалізовані параметри, **повний прайс на момент відправки** (`price_snapshot`) і результат розрахунку (`estimate`). Зміна тарифів у кабінеті не змінює вже надіслані заявки (перевіряється в `scripts/smoke.mjs`). Підсумкову ціну власник вводить вручну після розмови.
